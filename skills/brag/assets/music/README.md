در پوشهٔ cues، فایل JSON شبکهٔ ضرب و لحظه‌های برجسته را نگه می‌دارد؛ فایل Markdown خلاصهٔ متنی برای برنامه‌ریزی دارد. این داده‌ها با scripts/analyze_music_cues.py تولید شده‌اند و فقط راهنمای اختیاری زمان‌بندی‌اند. اگر cue موجود نیست، بدون همگام‌سازی ضرب ادامه بده.

این مجوز جدا از مجوز کد مخزن است؛ اعتباردهی موسیقی را هنگام انتشار ویدیو حذف نکن.
